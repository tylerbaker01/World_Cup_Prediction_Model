Capstone Project

I was curious about other factors that could be used to accurately predict the outcome of a World Cup. Most models use things like player stats, coach stats, etc. 
I wanted to see what non-expected results I could get from using country metrics such as GDP, population, amount of grain produced, literacy rates, among others.
I had a lot of fun with this project and I learned that country metrics performed just as well as player metrics did, and a combination of the two performed the 
best. In the end my prediction was that Brazil would win the 2022 World Cup.
